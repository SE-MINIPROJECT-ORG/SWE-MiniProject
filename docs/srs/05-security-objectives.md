# 5.1.1 Security Objectives

The following security objectives apply to the whole Event Management System. The security requirements in section 5.1.2 (EVT-SR-001 to EVT-SR-007) implement them.

| ID | Objective | Description | Related Requirements |
|----|-----------|-------------|----------------------|
| SO-1 | Confidentiality | Credentials and personal data of attendees, organizers and admins are protected from unauthorized access, in storage and in transit. | EVT-SR-001, EVT-SR-004, EVT-SR-005 |
| SO-2 | Integrity | Event, registration and attendance data can be created or changed only by authenticated users who hold the right role and own the data, and inputs cannot be used to corrupt the system. | EVT-SR-002, EVT-SR-003, EVT-SR-005 |
| SO-3 | Accountability and Availability | Security-relevant actions are recorded so they can be traced to a user, and abuse such as brute-force or request flooding is limited so the service stays available to genuine users. | EVT-SR-006, EVT-SR-007 |
